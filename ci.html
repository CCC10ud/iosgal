没有 Mac，怎么拿到 iOS 27 能装的真包 已验证

原生 App 源码已经做完（见 原生引擎说明）。卡在最后一步：编出 iOS 的 .ipa 必须用 macOS + Xcode，而本机是 Windows。这条文档给你一条不买 Mac 的通路——把工程推到 GitHub，让 GitHub 的 Mac 云机器免费帮你编译。

✅ 你已经有已经 git 提交好的干净仓库 zip（GalBoxNative-CI-repo.zip），只含原生工程，无网页壳
✅ 你只需要一个免费 GitHub 账号 + 任意能上网的 Windows 电脑 + 一台 iPhone
✅ 花多少钱公开仓库的 GitHub Actions 免费；侧载用免费 Apple ID 重签，也免费
⏱ 多久首次编译约 5–15 分钟；每 7 天免费签名到期，重签一次约 1 分钟

整体流程

① 建仓库github.com 新建空 Public 仓库 → ② 解压推送解压 zip，push 到 GitHub → ③ 等 CIActions 自动编出 .ipa（5–15 分钟） → ④ 下载取 Artifact 里的 adhoc.ipa → ⑤ 装手机Sideloadly 连 iPhone 重签安装

全程不需要 Mac。下面每一步都给了可复制的命令。

第一步 · 在 GitHub 建一个空仓库

  1. 打开 github.com/new（没有账号先注册，免费）。
  2. 仓库名随意，例如 galbox-native。
  3. 务必选 Public，不要勾选 "Add a README / .gitignore / license"（仓库必须完全空，否则 push 会被拒）。
  4. 记下仓库地址，形如 https://github.com/你的用户名/galbox-native.git。
私有仓库的 Actions 每月免费额度很小，且编 iOS 更受限；公开仓库完全免费，代码本身也只是个播放器框架，没有敏感信息。

第二步 · 解压并推送到 GitHub

先下载并解压 GalBoxNative-CI-repo.zip。解压后会得到一个已 git init 并提交好的文件夹，里面已经没有网页壳、没有 WKWebView，只有原生工程 + CI 脚本。

# 进入解压出来的文件夹（里面应该有 .git 目录和 ios-native/、native/ 等）
cd GalBoxNative-CI-repo

# 把远程指向你刚建的空仓库
git remote add origin https://github.com/你的用户名/galbox-native.git

# 推送（需要 GitHub 登录）
git push -u origin main

推送要登录怎么办：

  • 最省事：装 GitHub Desktop，图形化登录后直接拖文件夹发布；
  • 或命令行登录：去 GitHub → Settings → Developer settings → Personal access tokens，生成一个有 repo 权限的 token，push 时用户名填你的账号、密码填那个 token。

推送成功即触发下一步。

第三步 · 让 GitHub 的 Mac 帮你编译（自动）

  1. 打开你的仓库页面，点顶部 Actions 标签。
  2. 会看到一个叫 「Build GalBox Native iOS IPA」 的工作流，push 后自动开始跑；也可以点 Run workflow 手动重跑。
  3. 点进去看日志，约 5–15 分钟后显示绿色 ✅。
工作流会先做 C++ 引擎自检（真编译并跑 28 项断言），通过后才调 Xcode 出包；任何一步失败都会红，日志里能直接看到原因。

第四步 · 下载编好的包

  1. 构建成功后，在 Actions 运行详情页最下方 Artifacts 处下载 GalBoxNative-ios27-sideload。
  2. 解压后里面有两个包：
    • GalBoxNative-adhoc.ipa —— 这就是要装到手机上的包（ad-hoc 伪签，留给侧载工具重签）。
    • GalBoxNative-unsigned.ipa —— 裸包备份，一般不用。
  3. 另有一个 GalBoxNative-build-log Artifact，存了 xcodebuild.log，编译失败时才需要。
GitHub 的 Artifact 只保留 30 天，下载下来及时备份；免费 Apple ID 重签 7 天有效，到期重新走第五步即可。

第五步 · 装到 iOS 27（不需要 Mac）

  1. Windows 上装 Sideloadly（免费），iPhone 用数据线连电脑。
  2. Sideloadly 里选 GalBoxNative-adhoc.ipa，Apple ID 填你的免费苹果账号，点 Start 重签安装。
  3. 手机上：设置 → 通用 → VPN与设备管理（或"描述文件与设备管理"）→ 信任该 Apple ID 的开发者证书。
  4. 桌面出现 GalBox 图标即可打开。AltStore / SideStore 走同一套免费重签流程，任选其一。
重要：iOS 17.0.1 之后 CoreTrust 漏洞已被封，TrollStore / .tipa 在 iOS 27 上不可用。只能用"免费 Apple ID 重签"这种正规侧载路径，有效期 7 天，到期用同一工具点一下重签就行。

GalBoxNative-CI-repo.zip 里有什么

路径作用
ios-native/Xcode 原生工程：Swift UI + Objective-C++ 桥 + C++ 引擎，UIKit 写的游戏库/播放器
native/Engine/XP3 归档解析 + KAG 脚本解释器（真实字节级解析，非模拟）
tools/build_native.shCI 里实际调 Xcode 出包 + 伪签的脚本
tools/verify_ipa.py校验 ipa 里真有 arm64 Mach-O（杜绝空壳包）
.github/workflows/build-native-ipa.yml无 Mac 出包的核心：macOS runner 上跑自检 + 编译 + 上传 Artifact
dist/fixtures/C++ 引擎自检用的独立参考夹具（合法包 + 4 个坏包）
BUILD.txt一份纯文本的离线版出包说明

本机自检（不需要 Mac，随时可跑）

这些命令在本机 Windows 上就能验证引擎和出包链路没坏，跑完应全是 PASS：

python tools/xp3_fixture.py      # 生成/校验 XP3 夹具
python tools/verify_native.py    # 真编译并在 Windows 跑 C++ 引擎自检
python tests/native.test.py      # 原生工程静态校验
python tests/ci.test.py          # CI 出包链路 + 假包闭环校验

当前回归状态：native 137 PASS / 0 FAIL · ci 50 PASS / 0 FAIL。

能力边界（务必看清）

  • 这是一个原生骨架 + 真实 XP3/KAG 子集，不是完整 Kirikiroid2。
  • 不含：TJS2 虚拟机、完整 KAG 指令集、音视频解码、商用加密包滤镜。
  • 所以不能保证任意商业 galgame 直接跑；自制的、未加密的 XP3+KAG 游戏可以。
  • 要 100% 兼容商业作品，正路是编译 zeas2/Kirikiroid2 源码——本工程是它的轻量原生替代/学习骨架。
